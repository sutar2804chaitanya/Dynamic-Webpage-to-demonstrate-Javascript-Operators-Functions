# 🔤 JavaScript String Functions Demo

A simple and interactive web application built using **HTML, CSS, and JavaScript** to demonstrate commonly used JavaScript string methods.

The project provides a user-friendly interface where users can enter text and instantly explore various string operations such as calculating length, converting text case, trimming spaces, extracting characters, slicing strings, and splitting text.

---

## 🚀 Features

### ✅ String Length

Calculate the total number of characters in a string using the `length` property.

### ✅ Uppercase Conversion

Convert all characters in a string to uppercase using `toUpperCase()`.

### ✅ Lowercase Conversion

Convert all characters in a string to lowercase using `toLowerCase()`.

### ✅ Trim Spaces

Remove extra spaces from the beginning and end of a string using `trim()`.

### ✅ Character Extraction

Retrieve a character from a specific position using `charAt()`.

### ✅ String Slicing

Extract a portion of a string using `slice()`.

### ✅ String Splitting

Split text into separate words and display them in a formatted output using `split()`.

---

## 🛠️ String Functions Demonstrated

| Function        | Description                                   |
| --------------- | --------------------------------------------- |
| `length`        | Returns the number of characters in a string  |
| `toUpperCase()` | Converts text to uppercase                    |
| `toLowerCase()` | Converts text to lowercase                    |
| `trim()`        | Removes leading and trailing spaces           |
| `charAt()`      | Returns the character at a specified position |
| `slice()`       | Extracts part of a string                     |
| `split()`       | Splits a string into an array                 |
